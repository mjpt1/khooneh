# سیستم مدیریت شارژ ساختمان

## توضیحات پروژه

این پروژه یک سیستم کامل و اجراپذیر برای مدیریت، حسابداری و ارتباطات داخلی ساختمان است. این سیستم به صورت اختصاصی برای هاست‌های اشتراکی طراحی شده است و **بدون نیاز به Composer یا دسترسی SSH** اجرا می‌شود.

ویژگی‌های کلیدی شامل احراز هویت نقش‌محور، مدیریت ساختمان و واحدها، صدور شارژ ماهانه، پرداخت آنلاین (شبیه‌سازی شده) و دستی، سیستم تیکتینگ، ثبت و جستجوی قوانین، گفتگوی داخلی و گزارش‌های مالی فارسی می‌باشد.

## پیش‌نیازها

- وب سرور: Apache (با `mod_rewrite` فعال)
- نسخه PHP: **8.3 یا بالاتر**
- دیتابیس: MySQL 10.x / MariaDB
- دسترسی به phpMyAdmin برای مدیریت دیتابیس

## مراحل نصب و راه‌اندازی

برای راه‌اندازی این پروژه، مراحل زیر را دنبال کنید:

1.  **ایجاد دیتابیس:**
    - وارد پنل هاست خود (مانند DirectAdmin) شوید.
    - یک دیتابیس جدید با `collation` از نوع `utf8mb4_persian_ci` ایجاد کنید.
    - نام دیتابیس، نام کاربری و رمز عبور را یادداشت کنید.

2.  **ایمپورت ساختار جداول:**
    - وارد `phpMyAdmin` شوید و دیتابیس ساخته شده را انتخاب کنید.
    - به تب `Import` بروید و فایل `database/initial.sql` را انتخاب و ایمپورت کنید.

3.  **تنظیمات پروژه:**
    - فایل `config.php.example` را به `config.php` تغییر نام دهید.
    - فایل `config.php` را باز کرده و اطلاعات دیتابیس (نام دیتابیس، نام کاربری و رمز عبور) را که در مرحله اول ایجاد کردید، وارد نمایید.
    - مقدار `base_url` را به آدرس دامنه‌ی خود تغییر دهید.

4.  **آپلود فایل‌ها:**
    - تمامی فایل‌ها و پوشه‌های پروژه را در مسیر `public_html` یا پوشه‌ی مربوط به دامنه خود آپلود کنید.

5.  **تنظیم دسترسی‌ها:**
    - دسترسی پوشه‌ی `uploads` را روی `755` یا `777` تنظیم کنید تا امکان آپلود فایل‌ها فراهم شود.

6.  **پایان!**
    - اکنون با باز کردن دامنه خود در مرورگر، صفحه‌ی ورود به سیستم را مشاهده خواهید کرد.

## نکات مهم

- این پروژه از یک **Autoloader اختصاصی** استفاده می‌کند و نیازی به نصب وابستگی‌ها از طریق Composer ندارد.
- تمامی پیام‌ها، خطاها و واسط کاربری به زبان **فارسی** و **راست‌چین** طراحی شده‌اند.
- اولین کاربری که ثبت‌نام می‌کند، به صورت پیش‌فرض نقش `admin` را دریافت خواهد کرد. (این مورد باید در نسخه نهایی تکمیل شود).
